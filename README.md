# Program Manager — চালু করার নির্দেশনা

পিকনিক, বিদায় অনুষ্ঠান আর অন্যান্য আয়োজনের হিসাব রাখার অ্যাপ। কোড থাকবে GitHub-এ, আর লগইন ও তথ্য থাকবে Firebase-এ।

**এখন যা আছে (ধাপ ১, ২ ও ৩):** লগইন, ব্যবহারকারী ও অনুমতি, একাধিক প্রোগ্রাম, বয়সের দল (প্রতি প্রোগ্রামে নিজে ঠিক করা), নামসহ পরিবার ও অতিথির তালিকা, মাথাগোনা, চাঁদার হার ও জমা, নোট, ক্যালকুলেটর, ফিরিয়ে নেওয়া (আন্ডু), সারাংশ শেয়ার, বাজেট (খাত ও উপখাত, শুধু অ্যাডমিন), খরচ (কে দিলেন, কীভাবে দিলেন), স্পন্সর (নগদ বা জিনিস), হিসাব মেলানো, উপহার (বয়সের দল, ছেলে/মেয়ে ও ভাগ অনুযায়ী; নাম ধরে দেওয়ার চিহ্ন), পুরো প্রোগ্রামের এক্সেল ফাইল (নামানো বা হোয়াটসঅ্যাপ/মেসেঞ্জারে পাঠানো), ১২টি থিম, ৫টি ইংরেজি ও ৬টি বাংলা ফন্ট, বাংলা/ইংরেজি।


Firebase যুক্ত না করলেও অ্যাপ "ডেমো মোডে" চলবে। তখন তথ্য শুধু ওই ফোনেই থাকে।

---

## ধাপ ১: Firebase প্রজেক্ট বানানো

1. https://console.firebase.google.com এ গিয়ে **Add project** চাপুন। নাম দিন, যেমন `program-manager`।
2. বাঁ পাশের **Build → Authentication → Get started** চাপুন। **Sign-in method** থেকে **Email/Password** চালু করুন।
3. **Build → Firestore Database → Create database** চাপুন। অবস্থান হিসেবে `asia-south1 (Mumbai)` বেছে নিন, **production mode** রাখুন।
4. Firestore-এর **Rules** ট্যাবে গিয়ে `firestore.rules` ফাইলের পুরো লেখা বসিয়ে **Publish** চাপুন। ফাইলের ভেতরের অ্যাডমিন ইমেইল আপনার নিজের ইমেইল কিনা দেখে নিন।
5. ⚙️ **Project settings → Your apps → Web (</>)** চাপুন। একটা নাম দিয়ে অ্যাপ যোগ করুন। যে `firebaseConfig` দেখাবে, তার মানগুলো `firebase-config.js` ফাইলে বসান।

## ধাপ ২: GitHub-এ তোলা

1. GitHub-এ নতুন repository বানান, যেমন `program-manager` (Public)।
2. zip খুলে **সব ফাইল আর ফোল্ডার** (fonts, icons সহ) **Add file → Upload files** দিয়ে তুলুন।
3. **Settings → Pages** এ গিয়ে Source: **Deploy from a branch**, Branch: **main / (root)** দিয়ে Save করুন।
4. এক-দুই মিনিট পর লিংক পাবেন: `https://আপনার-ইউজারনেম.github.io/program-manager/`
5. Firebase-এ ফিরে **Authentication → Settings → Authorized domains** এ `আপনার-ইউজারনেম.github.io` যোগ করুন।

## ধাপ ৩: প্রথম লগইন

1. Firebase **Authentication → Users → Add user** চাপুন। আপনার অ্যাডমিন ইমেইল আর একটা পাসওয়ার্ড দিন।
2. অ্যাপের লিংকে গিয়ে সেই ইমেইল-পাসওয়ার্ডে প্রবেশ করুন। আপনি নিজে থেকেই অ্যাডমিন হয়ে যাবেন।
3. এরপর অ্যাপের **আরও → ব্যবহারকারী ও অনুমতি** থেকে অন্য আয়োজকদের যোগ করুন এবং টিক দিয়ে ঠিক করুন কে কোন অংশে এন্ট্রি দিতে পারবেন।

## ফোনে বসানো (iPhone)

Safari-তে লিংকটি খুলে **Share → Add to Home Screen** চাপুন। তখন এটি সাধারণ অ্যাপের মতো খুলবে।

## নতুন সংস্করণ তোলার সময়

`sw.js` ফাইলের ওপরের `VERSION` একটু বদলে দিন (যেমন `pm-v1.0.1`)। তাহলে সবার ফোনে নতুন সংস্করণ চলে আসবে।

## কয়েকটি জরুরি কথা

- কারও পাসওয়ার্ড ভুলে গেলে Firebase **Authentication → Users** থেকে বদলানো যায়।
- কাউকে বাদ দিতে চাইলে অ্যাপে তার **চালু আছে** বন্ধ করে দিন।
- ফাইলগুলো: `index.html` (মূল পাতা), `app.js` (অ্যাপের কাজ), `app.css` (নকশা ও থিম), `i18n.js` (বাংলা/ইংরেজি লেখা), `db.js` (Firebase সংযোগ), `firebase-config.js` (আপনার Firebase তথ্য), `sw.js` (অফলাইন), `fonts/` (SolaimanLipi ও Kalpurush)।

- ধাপ ২-এ `firestore.rules` বদলেছে (হিসাব মেলানোর লেনদেন যোগ হয়েছে)। আগে Rules বসিয়ে থাকলে নতুন ফাইলটি আবার বসিয়ে Publish করুন।
